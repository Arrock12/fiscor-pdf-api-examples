# Contributing

Thanks for improving the Fiscor PDF API examples.

## Guidelines

- Do not commit real API keys, private documents, or customer files.
- Keep examples small and production-oriented.
- Prefer environment variables for secrets.
- Include error handling for failed API calls and failed jobs.
- Use the live operations endpoint as the source of truth:

```txt
https://pdf.fiscor.am/api/v1/operations
```
